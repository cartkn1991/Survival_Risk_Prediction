# External phenotype exports (dbGaP)

Place dbGaP lifestyle CSV exports here before running the pipeline:

- `fhs_lifestyle_raw.csv`
- `whi_lifestyle_raw.csv`

Copy `bio_relevance/lifestyle_variable_map.example.json` to `bio_relevance/lifestyle_variable_map.json` and edit column names to match your export headers.

See [`feature_importance/bio_relevance/lifestyle/README.md`](../feature_importance/bio_relevance/lifestyle/README.md) for full instructions.
